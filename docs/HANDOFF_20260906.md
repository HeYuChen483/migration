# 2026-09-06 Handoff

This release is the final confirmed generation 7 paper_ball vision-to-localization route.

Do not replace it with generation 8 by default, and do not assume the old boxpaper stable supplement is part of this release. The included runtime profile disables the paper/box supplement and uses only the generation 7 paper_ball secondary route.

## Included Model

- `models/yolov8s-worldv2-garbage.onnx`
- `models/paper_ball_robotview_continue7_20260906_150818_best.onnx`
- Vision route: primary garbage model + secondary G7 `paper_ball` expert model
- Primary threshold: `PRIMARY_CONFIDENCE_THRESHOLD=0.18`
- G7 detector entry threshold: `PAPER_BOX_SECONDARY_DETECTOR_CONFIDENCE_THRESHOLD=0.06`
- Live paper_ball threshold: `PAPER_BOX_SECONDARY_CONFIDENCE_THRESHOLD=0.12`
- G7 crop profile: `PAPER_BOX_SECONDARY_FALLBACK_CENTER_CROP_SCALE=1.8`, `PAPER_BOX_SECONDARY_FALLBACK_CROP_MODE=center_bottom`
- RGB-D vote: disabled by default, `ENABLE_PAPER_BALL_RGBD_VOTE=false`
- Paper/box stable supplement: disabled by default, `ENABLE_PAPER_BOX_SUPPLEMENT=false`

## Not Included

- Final real-robot map: not built yet, so do not use an old map as the handoff map.
- Simulation packages / worlds: not part of the senior reproduction path.
- 2026-09-07 and later experiments: prompt A/B, console, Adapter/domain training, day-of training.

## Localization Rule

Use `/garbage_localization/stable_objects` for future navigation. Avoid using one-frame `/garbage_localization/objects` as a navigation target while the robot is moving.

If `xy_jitter_m.p95 <= 0.25-0.35m`, the far paper_ball target is probably usable for navigation. If it is above `0.5m`, debug AMCL initial pose, TF, and Kinect point-cloud sync before sending navigation goals.
